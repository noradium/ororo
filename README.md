# おろろの記録

## iPhone・Androidで家族共有するPWA版

新しいPWA版は [`web/`](web/) にあります。ホーム画面に追加でき、Firebaseの無料Sparkプランで家族のログイン・招待・記録の同期に対応します。Firebase未設定でも端末保存モードで使えます。セットアップと無料プランでの公開手順は [web/README.md](web/README.md) を参照してください。以下は既存のAndroidネイティブ版の説明です。

飼い猫のトイレ・ご飯の残り・嘔吐を記録する、シンプルなAndroidアプリです。
Android 8.0（API 26）以上で動作します。アカウントや通信は不要です。

## 使い方

- **猫の切り替え**：画面上部のモネ（グレーのブリティッシュショートヘアー）・ルノワール（白のラガマフィン）のカードを選びます。選択中の猫の名前を記録ボタンの上に表示し、最後の選択も覚えます。
- **うんち・おしっこ・嘔吐**：ボタンを押すと、その時刻で記録します。
- **ご飯廃棄**：朝・夜など、ご飯を交換するときに残っている量をグラムで入力します。食べきったときは `0` を入力できます。小数点以下2桁まで対応します。
- **カレンダー**：月を切り替え、日付を選ぶと、選択した猫だけの集計と新しい順の履歴を確認できます。日付の下の数字もその猫の記録件数です。「今日へ」で当日に戻れます。
- **猫の変更**：履歴の「猫を変更」から、記録した猫を修正できます。
- **削除**：履歴の「削除」を押し、確認すると記録を削除します。
- **書き出し**：2匹分と未分類を含むすべての記録を、猫の識別子付きのJSONファイルとして任意の保存先に書き出せます。取り込み機能はまだありません。

旧版の記録はどちらの猫か判別できないため、「未分類」として保持します。「未分類の記録を振り分ける」から履歴の「猫を選ぶ」で振り分けてください。未分類の表示中は新しい記録を追加できません。
更新するときは同じ署名のAPKを上書きインストールしてください。旧版をアンインストールすると記録が消えます。

カレンダーで過去の日を見ているときも、記録ボタンは**現在時刻**で保存し、今日の表示に戻ります。
1日のご飯記録回数に制限はありません。与えた量は記録しないため、食べた量は自動計算しません。

## データ保存

記録は端末内のアプリ専用領域にある `files/records.json` に保存します。
保存後はアプリを終了・再起動しても残ります。外部ストレージ権限やインターネット権限は使用しません。

- JSONバージョン2には記録ID、UTCエポックミリ秒、種類、廃棄量（ご飯以外はnull）、猫の識別子（`MONET`・`RENOIR`・`UNASSIGNED`）を保存します。バージョン1も読め、次の保存時に既存の記録を維持したままバージョン2へ更新します。
- 表示の日付・時刻は端末のタイムゾーンに従います。
- 一時ファイルに書き込み、同期してから置き換えます。保存に失敗した場合は画面上にも成功として反映しません。
- 保存ファイルの破損や非対応バージョンを検出した場合は、元のファイルを上書きせず記録を停止します。
- **アプリのアンインストールやストレージ消去で記録も消えます。** OSの自動バックアップは無効です。必要なデータは事前に書き出してください。

## ビルド

Java 17以上（この環境ではJava 21）、Android SDK Platform 35、Build Tools 35.0.0を使用します。
Gradle 8.11.1とAndroid Gradle Plugin 8.9.2を固定しています。

Android Studioでこのディレクトリを開くか、SDKの場所を `local.properties` に指定して実行してください。
`local.properties` は環境固有なのでGit管理しません。

```properties
sdk.dir=/path/to/android-sdk
```

```sh
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest :app:lintDebug
# USBデバッグで接続した端末へインストール
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

クラウド環境の既存チェックアウトは `/workspace/ororo` です。
SDKは `/workspace/android-tools/sdk` に配置しています。
ビルド結果は `app/build/outputs/apk/debug/app-debug.apk` に出力されます。

このクラウド環境にはJREだけが標準で入っているため、追加したJDKを選択してビルドします。

```sh
export JAVA_HOME=/workspace/android-tools/jdk/usr/lib/jvm/java-21-openjdk-amd64
export GRADLE_USER_HOME=/workspace/android-tools/gradle-home
./gradlew -Dhttps.proxyHost=proxy -Dhttps.proxyPort=8080 \
  -Dhttp.proxyHost=proxy -Dhttp.proxyPort=8080 \
  :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

## 確認項目

自動テストは4種類の保存・再読込・削除、0gの保存、ファイル破損、非対応バージョン、書き込み失敗時のデータ保護、タイムゾーンの日付境界、不正な量の拒否を確認します。
Robolectricで画面のボタン操作、入力検証、Activity再生成後の読み込み、削除確認も検証します。
2匹の記録・残量・カレンダー表示の分離、猫の選択の復元、旧データの未分類からの振り分け、振り分け失敗時の保護、猫の識別子付き書き出しも確認します。

端末では、各ボタンで記録 → ご飯を0g・小数で記録 → 月移動・日付選択 → 削除 → アプリ再起動 → JSON書き出しを確認してください。
